Detailed Description

High-level interface for interacting with system processes.

CSystem provides a platform-independent interface for common system operations such as:

  • locating processes
  • waiting for processes to start
  • querying process metadata

All platform-specific behavior is delegated to the provided IPlatformLink implementation.

Before using any functionality, the system backend must be initialized via initialize().

Error handling: Most operations report failures through the global error system. The last error can be retrieved using Error::getLast().
