std::string Azoth::Pattern::toString ( ) const
inline

Convert the pattern to a human-readable string.

Wildcard bytes are represented as "??". Non-wildcard bytes are printed as two-digit hexadecimal values.

Example output: "48 8B ?? ?? 89"
