Detailed Description

Fine-grained filter for matching memory protection states.

ProtectionFilter allows expressing requirements for individual protection flags independently. Each permission can be:

  • Ignore : do not care about this flag
  • Require : the flag must be present
  • Forbid : the flag must NOT be present
