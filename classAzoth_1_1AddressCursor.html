Resolves x86/x64 signed RIP-relative displacement targets.

Computes target address as: _address + instructionSize + (int32_t)displacement.

Parameters
offsetOffset from current address to the start of the 4-byte displacement operand.
instructionSizeTotal length of the instruction containing the displacement. Defaults to offset + 4 (standard for trailing displacements).
Returns
A new AddressCursor pointing to the absolute resolved target, or Invalid on failure.
