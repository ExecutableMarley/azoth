Detailed Description

Represents a loaded executable image or shared library in a process.

A ProcessImage describes a contiguous memory range that corresponds to a mapped binary image (e.g. executable or shared object), along with its identifying metadata.

Note
This class is purely descriptive and does not imply ownership or lifetime management of the underlying memory.
