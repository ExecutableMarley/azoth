Detailed Description

Cached copy of a contiguous remote memory region.

MemoryCopy provides a mechanism to copy a block of memory from a target process into a local buffer, operate on it locally, and optionally write it back to the target process.

Note
No automatic synchronization is performed and the caller is responsible for explicitly calling readIn() and writeBack().
